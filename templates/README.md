# Templates

Copy these into a consuming app on first factory stamp. Do not treat
this folder as a live queue or a product verify skill.

| Copy from | Copy to |
|---|---|
| `templates/factory/queue.md` | `factory/queue.md` |
| `templates/factory/README.md` | `factory/README.md` |
| `templates/.cursor/rules/factory.mdc` | `.cursor/rules/factory.mdc` |
| `templates/.cursor/rules/pstack-models.mdc` | `.cursor/rules/pstack-models.mdc` |
| `templates/verify-app/` | `.cursor/skills/verify-<app>/` (rename) |

The live queue, feature maps, and `AGENTS.md` invariants stay in the app.
